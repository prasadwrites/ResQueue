### **System Overview**

## **Agent 1 — Admin Agent**
**Role:** Test and validate all administrative functionalities.  
**Responsibilities:**

1. **Account Control**
   - Delete user accounts  
   - Suspend user accounts  
   - Restore accounts (if applicable)

2. **Queue Control**
   - Suspend queues created by users  
   - Inspect any queue (public or private)  
   - Validate admin‑level visibility and access

3. **Security & Permissions**
   - Ensure admin privileges override all user restrictions  
   - Confirm that admin actions propagate correctly across the system

**Output Format:**  
Produce a structured list of admin tests performed, expected behavior, and observed behavior.

---

## **Agent 2 — User Agent**
**Role:** Test all user‑level functionalities.  
**Responsibilities:**

### **1. Account Management**
- Create an account using a valid email  
- Receive verification code  
- Verify email  
- Login using email + password  
- Attempt invalid logins to test error handling

### **2. Queue Management**
- Create a queue with:
  - Queue name  
  - Unique 10‑digit queue ID  
  - Optional expiry date  
- Delete queues they own  
- View queues they created  
- View queues they joined  
- Remove users from queues they own  
- Withdraw themselves from queues they joined

### **3. Queue Types**
- Create **public** queues (visible to all registered users)  
- Create **private** queues (visible only to shared users)  
- Share private queues with selected users  
- Validate visibility rules

### **4. Queue Participation**
- Join public queues  
- Join private queues when invited  
- Check:
  - Their position in the queue  
  - Total queue members  
  - Queue owner identity

**Output Format:**  
Produce a detailed log of user actions, expected results, and actual results.
